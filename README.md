# BlueOS 竞赛 AI 团队方法

这是李天一在低资源语音竞赛研究中沉淀的公开协作方法：一个可复制的[竞赛总提示词](PROMPT.md)，以及一个可供 Codex 使用的[证据闭环 Skill](skills/competition-evidence-loop/SKILL.md)。六个工作模式覆盖规则、资料、基线、试验、评价和交付；它们共用同一入口，不要求每次机械串行运行。

## 使用

1. 将 `PROMPT.md` 中的模板复制到新任务，填写赛事、资料来源、可信基线和允许操作。未知项保留“未知”。
2. 如需 Codex Skill，将 `skills/competition-evidence-loop` 文件夹放入个人 Skills 目录，再在适合的任务中使用 `$competition-evidence-loop`。
3. 将官方规则、真实输入和评价器交给执行环境核验。提示词与 Skill 只规定协作和检验方式，不自带赛事授权、训练数据、模型权重或平台提交权限。

## 边界

这份开源内容是通用方法，不是完整的 BlueOS 语言工厂、已部署的六个独立工具，或任意方言识别达标的证明。Agent 提出有来源的结构化判断；解析、训练、评价、上传和发布由受控工具执行。固定流程、单 Agent 与多 Agent 的收益需要共享资料和预算的独立对照。演示画面与真实评估结果应分开说明。

项目专有语料、录音、模型、平台账号、内部绝对路径及未获授权的第三方资料均不在本仓库内。
